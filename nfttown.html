01

프로젝트 개요

배경 · 목적

NFT 시장이 빠르게 성장하는 가운데, 여러 플랫폼에 분산된 NFT를 통합 관리하기 어려운 사용자 불편을 해소하기 위해 기획된 프로젝트입니다.

NFT Town은 쉬운 NFT 관리와 사용을 목표로 하는 NFT 전문 포털 사이트로, 연동 지갑 Brezel Wallet과 함께 제공됩니다.

핵심 특징

  • NFT 통합 포털 — 여러 체인의 NFT를 한 곳에서 조회·관리
  • Brezel Wallet 연동 — NFT Town 전용 Chrome 확장 지갑 제공
  • 효성TNS 파견 — 클라이언트와 외부 업체 간 커뮤니케이션 직접 수행
  • F.O / B.O 동시 기획 — 프론트·백오피스 UI/UX 전반 설계
