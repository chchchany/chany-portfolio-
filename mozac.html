블록체인 기반 웹소설 플랫폼

창작자와 독자가 함께 만들어가는 블록체인 기반 웹소설 플랫폼. 서비스 기획부터 IA 설계, F.O/B.O UI/UX 기획, 퍼블리싱까지 전 범위 참여. 외부 블록체인 API 연동 및 TTA 소프트웨어 인증 6항목 통과.

블록체인 신규기획 IA 설계 UI/UX F.O / B.O 퍼블리싱 TTA 인증 5인팀
01

서비스 소개

MOZAC — 모두의 작품 · 블록체인 기반 웹소설 플랫폼
  • 카루스웍스 × ABC가 함께 만든 블록체인 기반 웹소설 플랫폼 — 창작자 보상 토큰 시스템과 콘텐츠 IP 소유권을 블록체인에 기록.
  • 독자가 직접 프로젝트에 투자하고 수익을 나누는 거버넌스 기반 공동창작 모델 설계.
  • 외부 블록체인 API 연동, 스마트컨트랙트 기반 토큰 발행·지급·조회 기능을 서비스 레벨에서 기획.

02

역할 & 기여

  • 서비스 기획 — 시장조사 및 경쟁 서비스 분석, 블록체인 웹소설 시장 데스크리서치, 백서 제작 참여 (기여도 50%)
  • IA 설계 (기능정의) — F.O 전 화면 메뉴 구조 설계. 1Depth~5Depth 화면코드 체계화, CMS 사용여부·접근권한 정의
  • UI/UX 기획 — F.O(프론트) 및 B.O(백오피스) 전 화면 와이어프레임 기획 (기여도 70%)
  • 퍼블리싱 — 모든 기능 및 테스트 화면 1인 단독 구현. 블록체인 트랜잭션 연동 UI 포함
03

IA 설계

전체 메뉴 구조 — 1Depth~5Depth · 화면코드 체계 · CMS 사용여부 · 접근권한 정의
  • 비로그인 / 로그인 Menu 분리 설계, 홈 · 창작피드 · 회원가입 · 마이페이지 등 전 영역 IA 커버
  • 각 화면에 고유 화면코드(MP_PC_XXXX) 부여 — 개발팀과의 소통 기준점으로 활용
  • CMS 사용여부, 접근권한(비로그인 / 로그인), 화면형식(Page / Popup / Modal) 전부 명세화
04

화면 설계

마이페이지 — 지갑(Wallet) · 진행중인 프로젝트 · 구독 화면 와이어프레임
  • 마이페이지 내 블록체인 지갑(Wallet) 연동 UI — MODAT 토큰 잔고, 코인 아이템 조회 화면 설계
  • 진행중인 프로젝트 카드 리스트 — 작품 참여 현황, 좋아요 / N화 표기 방식 기획
  • 구독 섹션 — 구독 중인 작품 썸네일 그리드 및 인터랙션 정의
05

TTA 소프트웨어 인증

✔ TTA 소프트웨어시험인증 — 6개 항목 전체 통과

CERT 01

초당 트랜잭션 처리용량

블록체인 1개 노드에서 초당 트랜잭션 처리 건수 측정. 특정 계정 토큰 잔고 10,000회 조회 TPS 측정.

목표: 1,000 TPS 이상 · 통과

CERT 02

트랜잭션 및 블록 송수신 시간

블록체인 등록 콘텐츠 데이터 검색 조건으로 100건 이상 동시 검색 응답 시간 측정.

목표: 5초 이내 · 통과

CERT 03

트랜잭션 처리 시간

블록체인에 100개의 콘텐츠 데이터 등록 후 트랜잭션 완료 시간 측정 (평균 건당).

목표: 평균 1초 이내 · 통과

CERT 04

플랫폼 동시접속자 수

45명 이상이 동시에 플랫폼 서비스에 접속하여 정상 동작 여부 확인.

목표: 45명 이상 동시접속 · 통과

CERT 05

거버넌스 체계 구현

플랫폼에 구현된 거버넌스 체계(보상 정책)가 시스템에 반영되어 정상 동작하는지 측정.

목표: 보상 정책 정상 적용 · 통과

CERT 06

블록체인 키 값 & 사용자 정보 연동

블록체인 키 값과 MOZAC 사용자 정보가 연동되는 트랜잭션을 블록에서 확인.

목표: 정상 연동 동작 · 통과
  • TTA 인증을 위해 직접 상암 TTA 방문 — 블록체인 API 테스트 시연 및 인증 진행
  • 외부 블록체인 API를 활용한 연동 작업 성공적으로 완료, 전체 인증 통과
