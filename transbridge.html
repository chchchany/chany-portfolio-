01

서비스 소개

Trans Bridge — 멀티체인 NFT 브릿지 플랫폼
  • ABC가 개발한 멀티체인 NFT 브릿지 — 서로 다른 블록체인 네트워크 간 NFT 자산을 자유롭게 이동할 수 있는 기술 기반 플랫폼.
  • MetaMask 연동을 통한 지갑 인증 후 NFT를 선택, 대상 체인으로 전송하는 B2C 브릿지 서비스와 기업 대상 B2B API 제공 구조로 기획.
  • 4개월간(2023.8 ~ 2023.11) 개발 완료 및 테스트 검증 후 투자자 미팅에서 직접 시연.

B2B

B2B 서비스 페이지 기획

블록체인 브릿지 API를 기업에 제공하는 B2B 구조 설계. 파트너사 온보딩 플로우, API 소개 페이지 UI/UX 기획. 기여도 100%.

브릿지 서비스 페이지 기획
