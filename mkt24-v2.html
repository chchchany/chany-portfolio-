마케팅24
신규 서비스 확장

마케팅24의 서비스 라인업을 본격적으로 확장하는 프로젝트를 단독으로 기획했습니다. 네이버 생태계 상품군 신규 추가부터 글로벌 API 연동, 수동 판매 구조 설계까지 플랫폼의 수익 구조를 다변화하는 전 과정을 담당했습니다.

신규 서비스 단독 기획 API 연동 정책 수립 서비스 확장
작업 1

네이버 블로그 활성화 상품 신규 기획

네이버 블로그는 국내 콘텐츠 마케팅에서 여전히 높은 비중을 차지하지만 마케팅24에는 관련 상품이 없었습니다. 블로그 활성화에 필요한 핵심 지표를 상품화하고, 뷰업과 연동되는 적립 구조까지 함께 설계했습니다.

상품 구성 설계

6개 상품 유형 정의

블로그 활성화에 필요한 6개 상품 유형을 정의했습니다.

  • 이웃 수 증가: 일 최대 100명 · 최대 5,000명 한도
  • 포스팅 공감 수 증가 (일반 / 키워드 검색)
  • 포스팅 댓글 증가 (일반 / 키워드 검색)
  • 커스텀 댓글 (일반 / 키워드 검색)
  • 스크랩 증가 (일반 / 키워드 검색)

각 상품별 주문 폼, 수량 범위, 단가 정책을 수립했습니다.

정책 수립

상품별 운영 정책 세분화

상품 특성에 따른 운영 정책을 세분화했습니다.

  • 하루 공감 최대 200개 · 댓글 최대 300개 제한 정책
  • 키워드 검색형: 75개 이내 조회 가능 조건 · 검색허용 차단 케이스 정의
  • 비공개·초기화 진행중·유효하지 않은 링크 등 유효성 검사 전 항목 정의
  • 광고주 차단 계정의 적립 불가 케이스 처리 방침 수립

뷰업 연동 설계

클릭뷰잉 + 오토뷰잉 적립 구조

마케팅24 블로그 활성화 주문을 뷰업 사용자가 클릭 또는 오토뷰잉으로 적립할 수 있는 구조를 설계했습니다.

  • 클릭뷰잉 + 오토뷰잉 모두 적용 (일반 댓글 제외)
  • 일일 적립 한도: 상품 유형별 30개 기준
  • 네이버 계정 등록 → 적립 시도 → 성공/실패 케이스 정의
  • 복붙 댓글 방지, 댓글 작성 시간 2분 제한 정책 수립
작업 2

플레이스 · 지식인 상품 신규 기획

네이버 플레이스와 지식인은 로컬 비즈니스와 검색 마케팅에서 수요가 높은 영역입니다. 기존 블로그 상품 구조와 일관성을 유지하면서 각 플랫폼 특성에 맞는 상품과 정책을 별도로 설계했습니다.

플레이스 상품

알림받기 · 저장 증가

플레이스 상품 구조를 설계했습니다.

  • 알림받기 증가: 키워드 75개 이내 조회 조건 · 일일 10개 적립
  • 저장 증가: 동일 구조 · 뷰업 클릭뷰잉 + 오토뷰잉 연동
  • 주문 폼: 플레이스 링크 + 키워드 입력 · 유효성 검사 정의

지식인 상품

답변 리액션 · 댓글 증가

지식인 상품 구조를 설계했습니다.

  • 답변 리액션 증가 (일반 / 키워드 검색)
  • 댓글 증가 · 커스텀 댓글 (일반 / 키워드 검색)
  • 뷰업 클릭뷰잉 + 오토뷰잉 연동 구조 동일하게 설계
작업 3

블로그 배포형 상품 유형 확장

기존 단일 배포형 구조에서 품질 단계별 상품 라인업으로 확장했습니다. 광고주가 예산과 목적에 맞게 선택할 수 있는 구조를 만들었습니다.

상품 유형 세분화

일반 / 간편 / 고품질 / 프리미엄 4단계 라인업

일반 / 간편 / 고품질 / 프리미엄 4개 유형으로 상품을 세분화하고 각 유형별 주문 폼, 가이드라인 정책, 이미지 처리 방식을 정의했습니다. HTML 기반 주문 내용 전달 방식(브라우저에서 바로 확인)과 이미지 별도 다운로드 구조도 이 단계에서 고도화했습니다.

작업 4

해외 API 상품 연동 기획

기존 국내 서비스 중심 구조에서 글로벌 SNS 마케팅 수요에 대응하기 위해 해외 패널 API를 통한 상품 확장을 기획했습니다. 서비스 설정 구조 전체를 재설계하고 운영 정책을 수립했습니다.

서비스 구조 설계

12개 채널 · 65개+ 상품 · 3단계 구조

인스타그램 · 유튜브 · 페이스북 · 틱톡 · X · 네이버 · 카카오 · 앱마케팅 · SEO · 디스코드 · 사운드클라우드 · 스포티파이까지 12개 채널의 65개 이상 상품을 채널 → 카테고리 → 상품 3단계 구조로 설계하고 어드민 서비스 설정 화면을 기획했습니다.

주문 정책 수립

일반 · 자동 · 패키지 3가지 주문 유형

일반 · 자동 · 패키지 3가지 주문 유형별 정책을 정의했습니다.

  • 분할 주문: n분마다 n개 파생 · 소수점 처리 · 24시간 초과 불가 정책
  • 오버플로우: 추가 수량 퍼센티지 설정 · 환불 제외 처리 기준
  • 패키지: 포함 상품별 진행률 산출 · 정지 시 환불 처리 방침
  • 실패 케이스: 재전송 · API 주문번호 추가 · 수동 상태 변경 흐름 정의

어드민 고도화

주문관리 운영 효율화

주문관리 전반의 운영 효율을 높이는 기능을 함께 기획했습니다.

  • 주문번호 다중 선택 복사 (마케팅24 번호 / API 번호 구분)
  • 부분취소(Set partial) 처리 및 환불 연동 정책
  • 주문 히스토리: 공급자 변경 · 상태값 변경 · 담당자 기록
  • 통계 리포트: 플랫폼별 판매순위 · 매출순위 전체 서비스 노출
작업 5

수동 API 판매 구조 설계

자동화된 API 연동이 어려운 상품군을 운영팀이 수동으로 처리할 수 있는 판매 구조가 필요했습니다. 별도 공급자 유형과 주문 관리 흐름을 새로 설계했습니다.

수동 API 구조 설계

공급자 유형 신규 추가 & 주문 흐름 정의

수동 API 공급자 유형을 신규 추가하고 주문 유형(URL · 휴대폰번호 · 계정 · 일 진행건수)에 따른 주문 폼과 상태값 관리 흐름을 정의했습니다.

  • 주문 상태: 대기 → 진행중 → 정지 / 완료 흐름
  • 주문 접수 시 메타모스트 알림 연동 설계
  • 수동 주문관리 별도 테이블 구성 (주문번호 · 채널 · 상품명 · 상태 · 설정)

Manual 상태 도입

해외 API 주문 수동 전환 구조

기존 해외 API 주문을 수동 처리로 전환할 수 있는 Manual 상태값을 신규 설계했습니다. 진행중 주문을 Manual로 전환하면 API 공급자와의 연결을 끊고 관리자가 직접 상태를 제어할 수 있습니다.

  • 분할 주문의 차일드 단위 Manual 전환 정책
  • 마더-차일드 상태 동기화 기준 정의
